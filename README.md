# Визуализатор зависимостей Maven

Учебное CLI-приложение для варианта № 27. Программа получает POM-файлы
Maven-репозитория по HTTP(S), строит граф прямых и транзитивных зависимостей
итеративным DFS, сохраняет D2 и SVG и находит обратные зависимости. Для
работы приложения достаточно Python 3.10+ и его стандартной библиотеки;
менеджеры пакетов и сторонние библиотеки не используются. Для реального
репозитория нужен доступ к сети. Сборка и установка зависимостей не нужны.

## Запуск в Windows

Полностью распакуйте проект и убедитесь, что в одной папке находятся
`run.bat`, `config.csv`, `src` и `examples`. Установите Python 3.10+
с добавлением в PATH. Откройте командную строку в папке проекта и выполните:

```bat
run.bat
```

По умолчанию используется тестовый граф `examples\repository.csv`. Программа
создаёт `output\graph.d2` и `output\graph.svg` и выводит пути к ним. Откройте
SVG в браузере. D2 — текстовое представление того же графа; SVG формируется
самостоятельно, поэтому установка D2 не требуется. При желании D2-файл можно
открыть в любом совместимом редакторе или передать установленному D2.

Граф по умолчанию можно открыть командой:

```bat
start output\graph.svg
```

При каждом запуске через `run.bat` прежние D2 и SVG заменяются. Чтобы защитить
существующие файлы от перезаписи, используйте `run.bat --no-overwrite`.
При прямом запуске через `python -m src.main` защита включена по умолчанию;
для явной перезаписи можно передать `--force`.

Если Windows сообщает об ошибке записи, закройте программы, которые могут
блокировать файлы, или выберите другой путь `output` в конфигурации. Входные
файлы конфигурации и репозитория нельзя использовать как файлы результата.
При неудачной замене программа пытается восстановить прежние результаты; если
откат не удался, в ошибке указаны пути к сохранённым резервным копиям.

```bat
run.bat
run.bat --config examples\junit.csv
run.bat --config examples\commons_text.csv
run.bat --config examples\slf4j_api.csv
run.bat --help
```

## Настройки

Конфигурация — UTF-8 CSV с точным заголовком `key,value` и пятью ключами:

```csv
key,value
package,A
repository,examples/repository.csv
test_mode,true
output,output/graph.svg
filter,
```

- `package`: имя пакета из заглавных латинских букв для тестового режима либо
  Maven-координаты `groupId:artifactId:version` для реального режима.
- `repository`: путь к CSV тестового репозитория или конечный HTTP(S) URL
  Maven-репозитория. HTTP-перенаправления не поддерживаются.
- `test_mode`: `true` для тестового CSV, `false` для Maven.
- `output`: путь SVG-файла. Файл D2 создаётся рядом с тем же именем.
- `filter`: подстрока, исключающая подходящие имена. Пустое значение ничего
  не исключает. Сравнение с полным идентификатором учитывает регистр.

Относительные пути `repository` и `output` отсчитываются от папки выбранной
конфигурации. Если фильтр совпал с корнем, результат — пустой граф. Исключённые
узлы не раскрываются, но их потомки могут остаться достижимыми по другому
пути. Ошибки параметров, POM и файлов выводятся в stderr, код возврата не ноль.

Используйте кодировку UTF-8, в том числе с BOM, и запятую как разделитель
столбцов. Если значение содержит запятую, заключите его в двойные кавычки:
например, `output,"папка, данные/граф.svg"`. Пробелы и кириллица допустимы.

## Тестовый репозиторий и обратные зависимости

CSV тестового репозитория имеет заголовок `package,dependencies`. В каждой
строке указано имя пакета из букв A–Z и его зависимости через `;`. У каждого
упомянутого пакета должна быть собственная строка. Пример:

```csv
package,dependencies
A,B;C
B,D
C,D
D,
```

Команды для графа без циклов, графа с циклами и фильтрации:

```bat
scripts\test_graphs.bat
run.bat --config examples\config_cycle.csv --force
run.bat --config examples\config_filter.csv --force
```

Обратные зависимости — прямые и транзитивные предки заданного узла:

```bat
run.bat --config examples\config_acyclic.csv --reverse LAMBDA
scripts\test_reverse.bat
```

Обратный поиск работает только в графе, достижимом от `package` после
фильтрации, а не во всём Maven Central. Сама цель не выводится даже при
цикле. Если цель отсутствует в графе, программа сообщает об ошибке. При
`--reverse` файлы не создаются; аргумент `--force` в этом режиме не нужен.

## Тесты и сравнение

```bat
scripts\test_config.bat
python -m unittest discover -s tests -t . -v
scripts\test_maven.bat
```

Модульные тесты используют стандартную библиотеку и фиктивные POM без сети.
Последний скрипт дополнительно загружает настоящие POM из Maven Central.
Если на компьютере установлен D2, один тест дополнительно проверит компиляцию
D2; без него этот тест пропускается. Официальный Maven необязателен для работы
программы; он нужен только для независимого сравнения:

```bat
scripts\compare_maven.bat
```

Результаты и порядок сравнения с `dependency:tree` приведены в
[отчёте](docs/comparison.md). В нём же ссылки на три готовых SVG и их D2.

## Ограничения разрешения Maven

Это учебный разбор опубликованных POM, а не полная реализация Maven Resolver.
Учитываются прямые зависимости `compile` и `runtime`, свойства POM, родители
и простые унаследованные `dependencyManagement`; `test`, `provided`, `system`,
`import` и `optional` исключаются. При построении графа POM каждого узла
анализируется отдельно. Конфликт версий и «ближайшая» зависимость Maven,
транзитивные `exclusions`, распространение scope и профили не реализованы.

Импорт BOM, диапазоны версий, `LATEST`/`RELEASE`, свойства среды и системы,
родительский `relativePath` и разрешение timestamped SNAPSHOT через metadata
не поддерживаются. Неизвестная версия или свойство приводят к ошибке, а не к
догадке. `type` и `classifier` учитываются при сопоставлении управления, но
не включаются в трёхчастный идентификатор графа. Из-за этих ограничений для
других пакетов результаты могут отличаться от Maven. Максимальный размер POM
— 2 МиБ, сетевой таймаут — 20 секунд; DTD/ENTITY запрещены.
