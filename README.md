# Визуализатор зависимостей Maven

Учебная консольная программа на Python 3.10+. Первый этап — проверка
конфигурации CSV и вывод всех параметров в виде `ключ=значение`.

## Запуск и тесты в Windows

```bat
run.bat --config config.csv
python -m unittest discover -s tests -t . -v
scripts\test_config.bat
```

## Настройки

Файл CSV в UTF-8 с заголовком `key,value` содержит пять обязательных ключей:

- `package` — координаты Maven `group:artifact:version` или имя из A–Z
  для тестового режима.
- `repository` — URL Maven-репозитория или путь к тестовому CSV.
- `test_mode` — `true` или `false`.
- `output` — имя будущего SVG-файла.
- `filter` — подстрока исключения; допускается пустое значение.

Относительные пути в CSV считаются от папки файла конфигурации. Ошибки
любого параметра выводятся в консоль с ненулевым кодом завершения.
