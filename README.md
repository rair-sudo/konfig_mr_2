# Визуализатор зависимостей Maven

Учебная консольная программа на Python 3.10+. На третьем этапе программа
читает настройки CSV и строит граф прямых и транзитивных зависимостей
с помощью DFS без рекурсии. Для получения зависимостей используются только
средства стандартной библиотеки Python, без вызова менеджера пакетов.

## Запуск и тесты в Windows

```bat
run.bat
run.bat --config examples\junit.csv
scripts\test_graphs.bat
python -m unittest discover -s tests -t . -v
```

## Настройки

Файл CSV в UTF-8 с заголовком `key,value` содержит пять обязательных ключей:

- `package` — Maven-координаты `group:artifact:version` или имя из A–Z
  для тестового режима.
- `repository` — HTTP(S) URL Maven-репозитория или путь к тестовому CSV.
- `test_mode` — `true` или `false`.
- `output` — имя будущего SVG-файла.
- `filter` — подстрока исключения; допускается пустое значение.

Относительные пути считаются от папки конфигурации. Строка фильтра ищется
с учётом регистра во всём идентификаторе; исключённые узлы не раскрываются.
Если совпадает корень, граф пуст. Обход защищён от циклов.

Тестовый CSV имеет заголовок `package,dependencies`. Имя пакета состоит
только из больших латинских букв, зависимости разделяются точкой с запятой;
для каждой упомянутой зависимости требуется отдельная строка. В `examples`
приведены графы без циклов, с циклами и с фильтром.
